- URL ของ repository: (กรุณาเติม URL ของ GitHub/GitLab repository ของคุณ)
- AI used for: guideline step by step และช่วยอธิบายความหมายของ dependencies รวมถึงร่างแนวคำตอบสำหรับตรวจสอบความถูกต้อง

## แบบฝึกหัด: ./mvnw dependency:tree

| library / starter | มีไว้ทำอะไร |
|---|---|
| spring-boot-starter-test | Starter หลักของ Spring Boot ที่รวบรวมไลบรารีจำเป็นสำหรับการเขียน Test ทั้ง Unit Test และ Integration Test มาให้ครบในตัวเดียว |
| junit-jupiter | เฟรมเวิร์กหลัก (JUnit 5) สำหรับเขียนโครงสร้างการทดสอบ กำหนด `@Test` ควบคุมวงจรชีวิตของเทสต์ และรันชุดทดสอบ |
| assertj-core | ไลบรารีสำหรับเขียนคำสั่งตรวจสอบผลลัพธ์ (Fluent Assertions เช่น `assertThat(...)`) ที่อ่านเข้าใจง่ายเหมือนภาษาอังกฤษและแจ้ง Error ได้ละเอียด |
| mockito-core | ไลบรารีสำหรับสร้างวัตถุจำลอง (Mock / Stub) เพื่อจำลองพฤติกรรมของคลาสหรือ Dependency ที่เกี่ยวข้อง ทำให้ทดสอบโค้ดแบบแยกส่วนได้อิสระ |
| spring-test (เพิ่มเติม) | เครื่องมือเสริมของ Spring Framework สำหรับช่วยจำลอง ApplicationContext และทดสอบการทำงานร่วมกับ Spring Beans หรือ Web Layer (เช่น MockMvc) |

## Reflection (2–3 ประโยคต่อข้อ)

1. **red bar แรกพิสูจน์อะไร ที่ green bar อย่างเดียวพิสูจน์ไม่ได้**
   red bar แรกพิสูจน์ว่าตัวทดสอบ (Test) ของเราทำงานได้จริง ถูกเรียกใช้งานจริง และสามารถตรวจจับความผิดพลาดเมื่อโค้ดยังไม่ทำงานตามเงื่อนไขที่ต้องการได้ ซึ่งหากเราเริ่มจาก green bar ทันทีโดยไม่เคยเห็น red bar มาก่อน เราจะไม่มีทางมั่นใจได้เลยว่าเทสต์นั้นผ่านเพราะโค้ดถูกต้องจริง หรือผ่านเพราะเทสต์เขียนผิดเงื่อนไขหรือไม่ได้ถูกรันเลยกันแน่

2. **ถ้าเครื่องของคุณหายวันนี้ จะกู้งานกลับมาได้จากที่ไหน**
   สามารถกู้งานกลับมาได้จาก Remote Repository บน Cloud (เช่น GitHub หรือ GitLab) ที่เราได้ทำการ `git push` โค้ดล่าสุดขึ้นไปเก็บไว้ เพียงแค่ใช้เครื่องใหม่ติดตั้งเครื่องมือพื้นฐานอย่าง Git และ JDK แล้วทำการ `git clone` โปรเจกต์ลงมา โค้ดทั้งหมด รวมถึงประวัติการแก้ไข (Commit history) ก็จะกลับมาพร้อมทำงานต่อได้ทันที
